# Hengda Overseas Sales Template Files

This folder contains separate templates for overseas customer development.

Use only confirmed product specifications in customer-facing emails. Do not add certifications, production capacity, technical data, or customer references unless they have been verified internally.

## Files

- `01-company-profile.md`: English company profile
- `02-product-information-template.md`: Internal product specification table
- `03-customer-qualification-fields.md`: Lead collection and qualification fields
- `04-first-contact-general-distributor.md`: First email for importers and distributors
- `05-first-contact-manufacturer.md`: First email for manufacturers
- `06-first-contact-construction-insulation.md`: First email for construction and insulation customers
- `07-reply-customer-interest.md`: Reply after a customer shows interest
- `08-follow-up-no-response.md`: First follow-up email
- `09-follow-up-final.md`: Final follow-up email
- `10-unsubscribe-handling.md`: Unsubscribe handling template
- `11-regional-notes.md`: Regional contact notes
- `12-do-not-say-unless-confirmed.md`: Claims and data to avoid unless confirmed
