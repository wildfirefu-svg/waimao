# Customer Qualification Fields

Use these fields in a spreadsheet or CRM before contacting a company.

| Field | Description |
| --- | --- |
| Company Name | Target company name |
| Country / Region | USA, Europe, Middle East, or Southeast Asia |
| Website | Official company website |
| Source URL | Where the lead was found |
| Contact Name | Leave blank if unknown |
| Email | Prefer department emails such as purchasing@, sales@, info@ |
| Industry | Construction, insulation, composites, trading, distribution, etc. |
| Product Fit | Fiberglass Yarn / Fiberglass Fabric / Both |
| Reason for Fit | Why this company may need the product |
| Contact Status | New / Drafted / Sent / Replied / Not Interested / Unsubscribed |
| Last Contact Date | Date of last email |
| Next Follow-up Date | Date for follow-up |
| Notes | Business details, product interest, language preference |
